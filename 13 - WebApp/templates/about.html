About This Project

Machine Learning Based Heart Disease Risk Prediction System

Project Overview

The Heart Disease Risk Prediction System is a machine learning based web application developed to estimate the likelihood of heart disease using patient medical information. The system analyzes multiple clinical parameters and generates a prediction that can support early health awareness.

The project combines Artificial Intelligence, Machine Learning, Data Science and Web Development technologies to create a simple, interactive and user-friendly healthcare application.

Project Objectives

Early Detection

Predict the likelihood of heart disease before serious complications occur.

Machine Learning

Utilize trained machine learning models to provide intelligent predictions.

Healthcare Support

Assist healthcare professionals with risk assessment and decision support.

User Friendly

Provide a simple and responsive web application for easy interaction.

Why Heart Disease Prediction?

Heart disease is one of the leading causes of death worldwide. Early identification of risk factors can improve treatment planning and encourage healthier lifestyle choices.

This application uses patient information such as age, blood pressure, cholesterol level, ECG results and other medical parameters to estimate heart disease risk using a trained machine learning model.

Technologies Used

Python

Used for data preprocessing, model training and backend development.

Flask

Provides backend services and connects the web interface with the machine learning model.

HTML • CSS • JavaScript

Used to create a responsive, attractive and interactive user interface.

Machine Learning

XGBoost model trained using patient medical records.
